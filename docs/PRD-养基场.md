# 养基场（FundFarm）产品需求文档（PRD）

| 项目 | 内容 |
| --- | --- |
| 产品名称 | 养基场（FundFarm） |
| 一句话定位 | 把基金自选管理做成「养鸡游戏」：领养一只鸡 = 持有一只基金，涨跌看得见、养基有乐趣 |
| 文档版本 | v1.0（初稿，待评审） |
| 撰写日期 | 2026-10-14 |
| 文档状态 | 待评审 → 待排期 |
| 目标平台 | 移动端 H5（主）/ PC Web（辅），响应式单套代码 |
| 适用对象 | 个人投资者（有基金持仓或自选关注习惯，非专业机构） |

## 1. 项目背景与目标

### 1.1 背景

- 基民的真实痛点不是「看不到数据」，而是「看了也拿不住」：净值波动带来的焦虑导致频繁查看、追涨杀跌。
- 现有基金 App 的数据密度高、情绪价值低，缺少「陪伴感」与「正反馈」，难以支撑长期持有。
- 游戏化（Gamification）在行为金融上的价值：把「短期波动」转译为「可消费的趣味事件」，降低情绪化操作频率，延长持有周期。

### 1.2 产品目标（业务目标）

| 编号 | 目标 | 衡量指标（上线 3 个月） |
| --- | --- | --- |
| G1 | 让自选基金管理「可玩、可坚持」 | 周活跃天数 ≥ 3 天的用户占比 ≥ 40% |
| G2 | 降低焦虑型频繁查看 | 人均日启动次数从 8+ 降至 3~5 次（用「每日任务 + 定时提醒」替代无目的刷新） |
| G3 | 沉淀个人投研资产 | 人均上传/生成分析报告 ≥ 2 份 |
| G4 | 形成自传播 | 成就卡片分享带来新用户占比 ≥ 10% |

### 1.3 用户目标

- 一眼看懂「我养的这些基今天怎么样」（涨了 = 鸡在产蛋，跌了 = 鸡在掉毛）。
- 用低成本的互动（喂食、抚摸、打扫）获得即时正反馈，对冲浮亏带来的负面情绪。
- 把分析报告、复盘记录沉淀在对应的基金下，未来可回看、可复盘。

### 1.4 非目标（本期不做）

- 不做真实交易、不接券商/基金销售、不代客理财。
- 不做社交动态流、不做公开收益排行（合规风险高，详见 §9.4）。
- 不做投顾建议/智能荐基（仅做「数据展示 + 用户自己上传的报告/AI 解析」）。

## 2. 目标用户与使用场景

### 2.1 用户画像

| 类型 | 特征 | 对养基场的核心诉求 |
| --- | --- | --- |
| A. 定投上班族（主力） | 25-40 岁，持 3-10 只基金，每月定投，白天不便盯盘 | 一眼看收益、被提醒定投、少焦虑 |
| B. 自选观察者 | 关注 10-30 只基金，频繁比价、犹豫不决 | 分组对比、估值提醒、报告沉淀 |
| C. 基民玩家/内容爱好者 | 爱晒收益、爱玩梗、爱收集 | 成就、图鉴、分享卡片、趣味文案 |

### 2.2 典型场景

| 场景 | 用户行为 | 产品应答 |
| --- | --- | --- |
| S1 开盘瞄一眼 | 通勤路上打开 App，想快速知道今天赚还是亏 | 鸡舍首屏：天气（大盘）+ 鸡群状态动画 + 今日总盈亏；跌了鸡在躲雨，涨了鸡在下蛋 |
| S2 新基金入池 | 朋友推荐一只指数基金 | 搜索基金代码 → 领养 → 选品种鸡 → 命名 → 归入分组「核心宽基」 |
| S3 深度研究 | 看到某只鸡连续掉毛，想知道为什么 | 进入基金详情 → 看净值/估值/持仓 → 上传研报 PDF → AI 解析出摘要与风险点 |
| S4 长期陪伴 | 持有 200 天，中间经历 -15% | 成就「风雨同舟」、时光机回看掉毛最多的那天的记录、鸡从雏鸡长成成鸡 |

## 3. 术语与概念表

| 术语 | 含义 |
| --- | --- |
| 养基场 / 鸡舍 | 用户的基金组合总览页，所有已领养的鸡生活在这里 |
| 领养 | 添加一只自选基金到列表，同时生成一只对应的虚拟鸡 |
| 放归（弃养） | 从自选中移除该基金（软删除，保留历史记录 30 天可撤销） |
| 分组 | 用户自定义的基金分类（如「核心宽基」「行业冲锋」「稳健打底」） |
| 鸡的品种 | 按基金类型映射的鸡形象（股票型=斗鸡、指数型=白羽鸡、债券型=芦花鸡、混合型=芦丁鸡、QDII=异域鸡、货币型=鹌鹑） |
| 成长值 / 等级 | 持仓时长 + 互动行为累积的经验值，决定鸡的外形阶段（雏鸡→仔鸡→成鸡→金鸡） |
| 饱食度 / 心情 / 健康 / 亲密度 | 鸡的四项状态值（0-100），由行情、互动、时间衰减共同决定 |
| 饲料 | 互动消耗品，通过签到、任务、成就获得，用于喂食 |
| 产蛋 / 掉毛 | 涨跌的正负反馈事件（涨 = 产蛋，跌 = 掉羽毛） |
| 天气 | 由大盘指数（上证/沪深 300）当日涨跌映射的鸡舍天气，影响全体鸡的心情 |
| 报告 | 用户上传或 AI 生成的基金分析文档（PDF/MD/图片/链接） |

## 4. 核心玩法：游戏化养基机制（FR-1）

### 4.1 主循环

```
领养（添加基金）
   ↓
每日行情 → 鸡产生状态事件（产蛋 / 掉毛 / 打盹 / 躲雨）
   ↓
用户互动（喂食、抚摸、打扫、听歌）→ 消耗饲料 → 恢复状态值 → 累积成长值
   ↓
成长值达标 → 鸡升级换形象 → 解锁成就与勋章
   ↓
成就与事件写入「养鸡日记」→ 可回看、可分享
```

### 4.2 领养流程（FR-1.1）

1. 输入/搜索基金代码或名称（调用外部接口搜索，见 §7.2）。
2. 系统按基金类型自动匹配鸡品种，用户可更换皮肤（后续解锁）。
3. 填写（可选）：昵称（默认取基金简称）、买入成本价、持有份额、首次买入日期、所属分组。
4. 点击「领养」→ 播放 3 秒孵化动画 → 进入鸡舍。
5. 领养成功即刻发放：成长值 +10、饲料 +10、成就「初次领养」。

> 规则：单用户最多领养 50 只（防止列表失控，超出提示「鸡舍满了，先放归几只吧」）。

### 4.3 行情 → 鸡状态映射规则（FR-1.2）

以**当日估值涨跌幅**（交易时段）或**日涨跌幅**（收盘后 / 非交易时段）为驱动信号 `p`：

| 涨跌幅区间 | 事件 | 鸡的表现 | 状态值变化 |
| --- | --- | --- | --- |
| p ≥ +2.0% | 下金蛋 | 站起来下蛋，金光特效，蛋入「蛋筐」 | 心情 +12，饱食 -2，成长值 +8，产蛋数 +1（金蛋） |
| +0.5% ≤ p < +2.0% | 下蛋 | 下蛋动画 | 心情 +8，成长值 +5，产蛋数 +1 |
| -0.1% < p < +0.5% | 散步/打盹 | 悠闲走动 | 心情 +2，成长值 +3 |
| -1.5% < p ≤ -0.1% | 掉羽毛 | 掉 1 根羽毛，毛发变暗 | 心情 -6，成长值 +2 |
| -3.0% < p ≤ -1.5% | 掉毛 + 打蔫 | 掉 3 根羽毛，蹲地 | 心情 -12，健康 -3，成长值 +1 |
| p ≤ -3.0% | 躲雨/生病 | 缩成一团，头顶乌云；若连续 3 天则进入「感冒」状态 | 心情 -20，健康 -8，成长值 -2 |

**叠加规则**

- 连续上涨天数 ≥ 3：触发「连蛋奖励」，当日成长值 ×1.5。
- 连续下跌天数 ≥ 3：触发「情绪低谷」，需要用户互动（喂食或抚摸）才能解除，否则成长值停止累积。
- 持有收益率 > 0 时，成长值每日额外 +5（「养得不错」）。
- 持有收益率 < -20% 时，鸡外观变瘦，但不死亡（明确设计：鸡永远不死，避免负罪感）。

**时间衰减（不打开也会变化）**

- 每 24 小时未互动：饱食度 -10，心情 -5，健康 -2（下限 20，不归零）。
- 饱食度 < 30：鸡头顶出现「饿」气泡，推送提醒（见 FR-7）。

### 4.4 状态值与互动（FR-1.3）

| 互动 | 消耗 | 效果 | 冷却 |
| --- | --- | --- | --- |
| 喂食 | 饲料 ×1 | 饱食 +25，亲密度 +3 | 每鸡每 2 小时 1 次 |
| 抚摸 | 免费 | 心情 +15，亲密度 +2 | 每鸡每 4 小时 1 次 |
| 打扫鸡舍 | 免费 | 全场健康 +8，心情 +5 | 每日 1 次 |
| 播放音乐 | 免费 | 全场心情 +10，持续 30 分钟 | 每日 2 次 |
| 加餐（道具） | 高级饲料 ×1 | 饱食 +50，成长值 +15 | 无 |

- 亲密度 ≥ 80 解锁「鸡会跟着手指跑」的彩蛋交互。
- 四项状态值均 ≥ 80 时，鸡进入「元气满满」状态，当日产蛋概率翻倍。

### 4.5 成长与等级（FR-1.4）

成长值来源：每日行情事件、互动、持有天数（每日 +2）、任务与成就奖励。

| 等级 | 成长值阈值 | 外形 | 解锁 |
| --- | --- | --- | --- |
| Lv.1 雏鸡 | 0 | 毛绒小球 | — |
| Lv.2 仔鸡 | 100 | 长出尾羽 | 解锁「抚摸」 |
| Lv.3 成鸡 | 300 | 完整成鸡造型 | 解锁品种特有动作 |
| Lv.4 壮鸡 | 800 | 鸡冠鲜红、体型健硕 | 解锁金色描边皮肤 |
| Lv.5 金鸡 | 2000 | 金色羽毛 + 光环 | 解锁「金鸡报晓」成就卡片 |

> 等级只反映「陪伴时长与照料投入」，**绝不与收益率挂钩**，避免把亏损羞辱化。这一点是产品价值观，需在设计稿文案中明确。

### 4.6 饲料与道具经济（FR-1.5）

| 获取途径 | 数量 | 说明 |
| --- | --- | --- |
| 每日签到 | +5（连续 7 天 +20） | 签到日历，断签重置 |
| 每日任务完成 | +3 / 项 | 见 §5.2 |
| 成就解锁 | +10 ~ +50 | 按成就等级 |
| 首次上传报告 | +30 | 引导投研沉淀 |

道具（后续版本）：雨伞（当日下跌时掉毛减半）、幸运草（次日产蛋翻倍）、闹钟（提醒不漏看）、时光机（回看历史某天）。

### 5.4 成就系统（FR-5）

成就分四类，共 30+ 枚，勋章墙展示已解锁/未解锁（未解锁显示灰色轮廓 + 达成条件）。

| 类别 | 示例成就 | 达成条件 |
| --- | --- | --- |
| 领养 | 初次领养、鸡舍兴旺、品类齐全 | 领养 1 / 10 只；集齐 5 种基金类型 |
| 陪伴 | 七日之约、百日守护、周年纪念 | 连续签到；某只鸡持有 100 / 365 天 |
| 心态 | 风雨同舟、扭亏为盈、岿然不动 | 经历 -15% 后回本；连续 30 天未新增领养（不追涨） |
| 投研 | 好学基民、报告达人 | 上传 1 / 10 份报告 |
| 彩蛋 | 夜猫子、早起鸟 | 凌晨 1 点后查看鸡舍 / 早 7 点前签到 |

成就解锁：全屏弹窗 + 撒花动画 + 分享卡片 + 饲料奖励。

## 6. 报告上传与 AI 接口预留（重点需求）

### 6.1 上传入口（FR-4.5）

位置：基金详情页「研究报告」卡片区。

- 支持方式：本地文件上传（PDF / Markdown / TXT / PNG-JPG）、粘贴文本、填写外部链接。
- 单文件 ≤ 20 MB，单基金 ≤ 50 份报告。
- 上传后记录：标题、来源（用户/AI/链接）、上传或生成时间、标签（`#季报` `#调研` `#风险`）、解析状态（待解析/解析中/已完成/失败）。
- 列表按时间倒序，支持删除、重命名、置顶、添加备注。

### 6.2 报告解析（FR-4.6）

- 用户上传后可选择「用 AI 解析」，服务端提取文本 → 调用大模型 → 输出结构化 JSON 并落库：

```json
{
  "fund_code": "005827",
  "report_title": "易方达蓝筹精选 2026Q2 季报解读",
  "report_date": "2026-07-20",
  "source": "user_upload",
  "summary": "季度净值 +6.2%，跑赢沪深300 约 3.1pct，主要来自白酒与港股互联网仓位贡献。",
  "key_points": [
    "股票仓位由 92% 降至 88%，现金比例提升",
    "前十大重仓集中度由 68% 升至 74%"
  ],
  "risks": ["行业集中度高", "港股仓位汇率敞口"],
  "sentiment": "neutral",
  "rating": null,
  "confidence": 0.72,
  "raw_text_length": 18420,
  "model": "hy3"
}
```

- 解析结果在详情页以「AI 摘要卡片」展示，并显著标注「由 AI 生成，仅供参考，不构成投资建议」。
- 解析失败需给出明确错误与重试按钮，不静默失败。

### 6.3 对外 API（供 AI Agent / 自动化调用）

统一前缀 `/api/v1`，鉴权：`Authorization: Bearer <API_KEY>`（用户可在「设置 - 开发者」中生成与吊销，密钥仅存哈希）。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/funds` | 获取自选列表（含分组、持仓、鸡状态） |
| GET | `/api/v1/funds/{code}` | 单只基金详情 |
| POST | `/api/v1/funds/{code}/reports` | **上传/创建报告**（`multipart/form-data` 或 `application/json`） |
| GET | `/api/v1/funds/{code}/reports` | 报告列表 |
| GET | `/api/v1/reports/{id}` | 报告详情（含解析结果） |
| DELETE | `/api/v1/reports/{id}` | 删除报告 |
| GET | `/api/v1/achievements` | 成就与解锁状态 |
| GET | `/api/v1/health` | 健康检查 |

上传报告请求示例（JSON 方式）：

```bash
curl -X POST https://<domain>/api/v1/funds/005827/reports \
  -H "Authorization: Bearer fa_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "易方达蓝筹精选 2026Q2 季报解读",
    "report_date": "2026-07-20",
    "tags": ["季报", "AI生成"],
    "content_type": "markdown",
    "content": "## 一、业绩回顾\n...",
    "parse": true
  }'
```

响应：`201 Created`，返回 `{"id":"rpt_xxx","status":"parsing"}`；解析完成后 `status` 变为 `done`，可通过 GET 拉取结构化结果。

### 6.4 面向 AI 的提示词（页面可一键复制）

产品需在「研究报告」区提供「复制 AI 调用提示词」按钮，复制内容模板如下（占位符自动替换为当前基金与用户域名）：

```
你现在是「养基场」的基金研究助手。目标基金：{基金名称}（代码 {基金代码}）。

任务：
1. 检索并阅读该基金最近一期季报/年报、近期净值表现、基金经理观点、行业动态。
2. 输出一份不超过 800 字的分析报告，使用 Markdown，结构如下：
   - 一、业绩回顾（近 1 月 / 近 1 年 / 同类排名）
   - 二、持仓与风格变化
   - 三、关键风险（列 3 条）
   - 四、后续观察指标（列 3 条）
3. 全文不得出现「建议买入/建议卖出/必涨」等投资建议表述，仅陈述事实与数据。

完成后，调用养基场接口把报告写回（需要用户已授权 API Key）：

POST {站点域名}/api/v1/funds/{基金代码}/reports
Headers: Authorization: Bearer {API_KEY}; Content-Type: application/json
Body: {
  "title": "<报告标题>",
  "report_date": "<YYYY-MM-DD>",
  "tags": ["AI生成"],
  "content_type": "markdown",
  "content": "<Markdown 正文>",
  "parse": true
}

最后向我回复：报告已写入，并附 3 条要点摘要。
```

同时提供机器可读的能力描述文件，便于 AI Agent 自动发现：

- `/.well-known/ai-plugin.json`：接口清单与鉴权方式（不含任何用户数据）。
- `/llms.txt`：面向大模型的站点说明与接口速查。

> 安全要求：API Key 仅对应用户自身数据；上传文件需做类型白名单、大小限制、病毒扫描（可选）；报告内容在展示时做 HTML 转义，禁止渲染脚本；`parse` 调用大模型需限流（建议 5 次/分钟、30 次/日）。

- 服务端统一代理，禁止前端直连第三方（规避 CORS 与 Referer 限制）。

- 所有数据页面固定展示免责声明：数据来自第三方公开接口，可能存在延迟或误差，不构成投资建议。

## 9. 非功能需求

### 9.1 性能

| 指标 | 要求 |
| --- | --- |
| 首页首屏 | LCP ≤ 2.5 s（4G），服务端渲染首屏 |
| 行情刷新 | 50 只基金批量拉取 P95 ≤ 800 ms（服务端缓存命中时 ≤ 200 ms） |
| 动画 | 群鸡动画稳定 60 fps（低端机降级为静态图 + 单只动画） |

### 9.2 可靠性与数据

- 行情全部失败时，页面仍可完整使用（展示本地缓存值 + 数据时间戳）。
- 用户数据（自选、报告、成就）每日自动备份，保留 14 天；支持一键导出。
- 报告文件与数据库分离存储，文件按 `userId/reportId` 隔离，防越权访问。

### 9.3 安全

- 所有接口校验用户身份与资源归属（防止越权读写他人报告）。
- 上传：类型白名单、大小限制、重命名存储、禁止脚本内容渲染（转义输出）。
- API Key 仅存哈希，展示一次；支持吊销与按 Key 限流。
- 密码使用 bcrypt 存储；登录失败限流；支持会话过期。
- 第三方行情请求由服务端发出，禁止把用户可控参数直接拼进外部 URL（防 SSRF）。

### 9.4 合规

- 明确「非投资顾问、非销售平台」定位，全站无买入/卖出建议与一键申购入口。
- 数据页与报告页固定展示免责声明；AI 生成内容强制标注来源与「仅供参考」。
- 不做公开收益排行与收益晒单广场，避免因展示收益引发的合规风险；分享卡片默认不含金额（可手动勾选）。
- 第三方数据仅用于个人学习研究，遵守来源站点 robots 与使用条款，控制请求频率。

## 附录 B：趣味文案库（示例）

- 上涨：「易方达蓝筹下了一枚蛋，快去捡」
- 下跌：「招商中证白酒掉了 3 根毛，需要安慰」
- 大跌：「外面下暴雨，鸡都躲进窝里了」
- 长期持有：「这只鸡已经陪你 200 天，它记得你每一次抚摸」
- 连续下跌 3 天：「它有点蔫，摸摸头吧（不摸也没关系）」
