# 养基场 FundFarm

把基金自选管理做成「养鸡游戏」：领养一只鸡 = 持有一只基金，涨跌变成产蛋与掉毛，让枯燥的持仓管理变得有趣。

需求文档见 [`docs/PRD-养基场.md`](./docs/PRD-养基场.md)（v1.1：V1.0 已上线，V1.1 迭代已同步进文档），本仓库为 MVP（V1.0）实现。

## 技术栈

- 后端：Node.js + Express 4 + SQLite（better-sqlite3）
- 前端：原生 ES Module SPA（hash 路由）+ CSS 变量主题，无构建步骤
- 鸡的形象：SVG 动态生成（随品种、等级、状态变化），无外部素材依赖
- 行情：服务端代理第三方公开基金接口，带缓存、降级与失败兜底

## 快速开始

```bash
npm install
cp .env.example .env        # 修改 SESSION_SECRET 等
npm start                   # 默认 http://127.0.0.1:3290
```

首次打开页面可用「游客模式」直接进入，也可注册账号（数据会保存在服务端 SQLite）。

可选：在 `.env` 中配置 `HUNYUAN_API_KEY`，即可使用大模型解析上传的研究报告；未配置时自动退化为本地摘要，功能不受影响。

## 搜索

领养弹窗的基金搜索带**自动联想补全**（`public/js/autocomplete.js`）：

- 输入代码、名称或拼音首字母（如 `005827` / `易方达蓝筹` / `yfdlc`）即触发防抖联想（250ms，请求带序号防竞态）
- 支持 ↑↓ 选择、回车确认、Esc 关闭；鼠标点击同样可选
- 选中后自动填充基金代码与昵称，联想数据来自 `/api/v1/search`（服务端 10 分钟缓存）

## 每只基金一只不同的鸡

品种（breed）由基金类型决定（股票型=斗鸡、指数=白羽鸡、混合=芦丁鸡、债=芦花鸡、QDII=异域凤冠鸡…），
同一品种下的不同基金再用**基金代码派生外观**（`src/engine/chicken.js` 的 `lookOf`），所以两只指数基金的鸡也长得不一样：

| 维度 | 取值 |
| --- | --- |
| 体色 | 品种基础色在 HSL 空间做色相/明暗偏移（近白色品种走色温 + 明度区间，避免荧光色） |
| 图案 | 纯色 / 圆点花 / 条纹 / 拼色 / 白肚 / 麻点（裁剪在身体轮廓内） |
| 配饰 | 无 / 围巾 / 眼镜 / 蝴蝶结 / 铃铛 / 小帽 |
| 鸡冠 | 三瓣 / 云冠 / 单冠 / 绒球 |
| 尾巴 | 扇形 / 卷翘 / 长翎 / 短尾 |
| 体型 | 四种比例（胖瘦高矮、头围、腿长） |

外观由 `hash32(基金代码|品种)` 稳定派生，换设备、重装、重新登录都不会变；
等级只影响体型缩放与金鸡光环，不会改变花色。

鸡舍 / 自选卡片副标题显示的是**实际基金分类**（东财 `FTYPE`，落到 `funds.category`），例如
`指数型-股票`、`指数型-海外股票`、`混合型-偏股`、`债券型-信用债`、`货币型-普通货币`；
品种与花色名（如「白羽鸡·麻点·眼镜」）保留在 `title` 提示与详情页，指数基金还会在「基金档案」里显示跟踪指数。

`GET /api/v1/explore?type=&sort=&page=&size=` 新增 `type=hb`。

## 涨跌幅实时刷新

涨跌幅不是「打开页面那一刻」的快照，而是在页面停留期间持续更新：

- 前端 `public/js/live.js` 轮询 `GET /api/v1/quotes`（交易时段 20s、非交易时段 120s，页面切后台暂停、切回前台立即补刷）
- 只就地更新带 `data-live-*` 标记的节点（涨跌幅、估算净值、今日估算、涨/跌家数、大盘），不整页重渲染，不打断滚动
- 服务端该接口要求数据不老于 15s（`estimateCache` 常规 TTL 60s，实时模式按「写入时间」判定），且同一基金并发回源自动合并
- 接口只读，不结算鸡的成长值 / 饱食度，轮询不会把鸡刷饱

盘中涨跌幅的取值顺序：

1. 天天基金 `fundgz` 实时估值（当前该接口大面积 404，基本取不到）
2. **按持仓实时估算**：取最新披露的前十大持仓（天天基金 f10，缓存 7 天）+ 个股实时行情（腾讯 `qt.gtimg.cn`，缓存 30s），按占净值比例加权得出 `Σ(权重 × 个股涨跌)`；持仓覆盖率 ≥ 50% 才采用，标记为 `approx: true`、界面显示「按最新持仓实时估算」
3. 都不可用时退回最新净值日涨跌幅（`live: false`，界面提示「数据可能延迟」）

| 类型 | 展示 |
| --- | --- |

| 债券型 | **重仓债券**（代码、简称、占净值比例、市值）+ 久期 / 信用等级提示 |
| 货币型 | 「货币基金怎么看」说明（7 日年化 / 万份收益 / 规模 / 赎回速度） |
| 有主题数据的（如消费类） | **关联板块 / 主题**标签，带板块近 1 月涨跌 |

均带报告期标注（如「截至 2026-06-30」）。
`getFundProfile` 对**指数型同时请求股票与债券持仓**（债券指数基金没有股票持仓，只抓 jjcc 会导致整块空白），

两者都取不到时显示「暂时取不到这只基金的持仓披露」并给出东财原始持仓链接。

## 收益与体型

- 鸡舍 / 自选卡片在今日涨跌幅下方显示 **持仓盈亏**：金额 + 收益率，如 `-15,833.00（-32.9%）`（`profit` 与 `profitRate` 同色，红涨绿跌），
  并附体型标签；未建仓显示 `--`；金额隐藏模式下只显示 `***`（不再附带收益率，避免侧漏）
- 卡片底部那行是 **仓位占比**（`item.marketValue / summary.marketValue`，前端算，保留一位小数），一眼看出钱主要压在哪只鸡上；
  鼠标悬停显示「持仓市值 + 占比」（鸡的成长等级已从所有页面下线，卡片不再有 Lv 徽章）
- 鸡的体型由**累计收益率**决定（`chickenEngine.buildOf()` → `chicken.build`），前端 `public/js/chicken.js` 按 `build.key` 缩放身体椭圆：

| 收益率 | 体型 | 身体缩放（rx × ry） |
| --- | --- | --- |
| ≤ -30% | 暴瘦 | 0.70 × 0.86 |
| -30% ~ -10% | 瘦 | 0.84 × 0.92 |
| -10% ~ 0 | 偏瘦 | 0.92 × 0.97 |
| 0 ~ 15% | 匀称 | 1 × 1 |
| 15% ~ 30% | 微胖 | 1.06 × 1.04 |
| 30% ~ 60% | 胖 | 1.12 × 1.08 |
| > 60% | 肥嘟嘟 | 1.18 × 1.12 |

体型只影响身体轮廓（花色、配饰、鸡冠、尾巴仍由 `look` 决定），与健康值过低的「虚弱瘦」叠加时取更瘦的一档。
标签在鸡舍卡片、自选卡片、详情页头部都会显示（亏损红底、盈利绿底）。

**卡片背景也跟着体型变**（`yardBgClass()` / `yardBgFx()`，`public/js/chicken.js`）：不看数字，扫一眼背景就知道这只鸡养得好不好。

| 收益率 | 氛围（class） | 背景 | 动画 |
| --- | --- | --- | --- |
| ≤ -30% | `bg-cold` | 冷蓝灰，阴沉 | 斜细雨丝下落 + 天光缓慢呼吸 |
| -30% ~ -10% | `bg-drizzle` | 灰青，潮湿 | 稀疏雨丝（更慢） |
| -10% ~ 0 | `bg-breeze` | 淡青绿，微凉 | 仅天光浮动 |
| 0 ~ 15% | `bg-grass` | 常见草地绿 | 仅天光浮动 |
| 15% ~ 30% | `bg-sunny` | 暖绿偏鹅黄 | 上升光点（金光闪烁） |
| 30% ~ 60% | `bg-golden` | 金黄 | 光点更密 |
| > 60% | `bg-party` | 暖橙庆典色 | 彩色纸带飘落 + 天光 |

所有氛围共用「右上光晕（`yb-glow` 8s 呼吸）+ 底部小土坡（`::after`）」两层，鸡本体 `z-index:3` 永远在最上层；
粒子层 `.bg-fx` 用 `box-shadow` 复制出多点位，单个元素即可画一整片雨 / 光点 / 彩带。
`prefers-reduced-motion` 下全部静止（光点保留静态微光）。收益氛围会**覆盖**「下雨天气」的旧底色。

**神情与动作也跟着体型变**（`public/js/chicken.js` 的 `ck-anim ck-<build>` + `style.css` 的 `.ck-*` 动画）：

| 体型 | 神情 | 动作 |
| --- | --- | --- |
| 暴瘦 | 半睁眼皮压下来、瞳孔无光，额角挂虚汗 | 大幅缓慢摇摆（6s），翅膀几乎不动 |
| 瘦 | 半睁眼、眼皮下垂 | 无力摇摆（4.8s） |
| 偏瘦 / 匀称 | 圆眼 + 高光，偶尔眨眼 | 轻微呼吸起伏（4.2s），眨眼 5.2s |
| 微胖 / 胖 | 眯眼笑 `^ ^` + 腮红 | 欢快小跳（2.8s），翅膀扇得更快（1.1s），眨眼 3.4s |
| 肥嘟嘟 | 眯眼笑 + 腮红 + 头顶小星星 | 跳得更勤（2.1s） |

生病或心情差时仍优先显示下垂的「难过眼」（覆盖体型神情）。眼睛用独立的 `<g class="ck-eye">` 做 `scaleY` 眨眼，防止两只眼连在一起抖动。
系统开启「减弱动效」时全部静止。

## 基金健康指标

基金详情页首屏显示的是**基金真实健康指标**（东财口径，`quote.getFundInfo` 的 `metrics`），共 12 项，分两组：

- **左上 · 区间涨跌**（8 项）：**单列整行**（`.m-row`：标签 52px + 条形 + 数值 64px），收窄到左半栏；
- **右上 · 关键指标**（8 项）：与左栏 1:1 对齐的纯数值行（标签 + 点线引导 + 数值）：
  近 1 周 `SYL_Z`、年化收益（成立来年化）、卡玛比率（近 3 年年化 ÷ 最大回撤）、月度胜率（近 24 个月上涨月份占比，按净值算）、
  基金规模 `ENDNAV`、成立年限 `ESTABDATE`、前十持仓占比（`profile.stockPercent` / `bondPercent`，>100% 为含杠杆）、申购费率 `RATE`（悬浮显示原价 `SOURCERATE`）；
  货币基金等缺项时用「申购状态 `SGZT`」「起购金额 `MINSG`」补位；
- **下半 · 风险与性价比**（4 项）：**两列**（`.metric-grid`）：最大回撤 / 年化波动 / 夏普比率 / 风险等级。

左右分栏用 `.health-cols`（`1fr 1fr`），≤900px 自动堆叠成一列。

图形语言只有三种，且全部在块底部有 `.m-legend` 图例说明：

1. **收益条**（8 个区间 + 夏普）：**共用一把尺子**——收益类统一 ±50% 刻度、中线为 0，长度可横向比较；正红负绿（A 股习惯）。
   夏普单独以 ±3 为刻度（单位不同，但同样中线为 0）。
2. **风险区间条**（回撤 / 波动）：红黄绿三段底色 + 黑色游标，游标落在哪一段就是哪一档，
   一眼能看出「这只基金的回撤处在什么水平」，不再用一个含义不明的长度条。
3. **风险等级**：5 格刻度，整条同色（R1~R2 绿、R3 黄、R4 橙、R5 红），填满几格 = R 几。

| 指标 | 字段 | 展示 |
| --- | --- | --- |
| 近 1 月 / 近 3 月 / 近 6 月 | `SYL_Y` / `SYL_3Y` / `SYL_6Y` | 收益条（±50%） |
| 今年来 / 近 1 年 / 近 2 年 / 近 3 年 / 成立来 | `SYL_JN` / `SYL_1N` / `SYL_2N` / `SYL_3N` / `SYL_LN` | 收益条（±50%，超界按满格） |
| 最大回撤 | `MAXRETRA1` | 区间条：<20 绿 / 20~40 黄 / >40 红 |
| 年化波动 | `STDDEV1` | 区间条：<15 绿 / 15~25 黄 / >25 红 |
| 夏普比率 | `SHARP1` | 双向条 ±3，≥1 红；货币基金波动趋 0 导致 \|夏普\| >10 时不展示 |
| 风险等级 | `RISKLEVEL` | 5 格刻度（R1~R5） |
| 申购费率 / 原费率 | `RATE` / `SOURCERATE` | 右栏数值，`'0.10%' → 0.1` |
| 申购状态 / 起购金额 | `SGZT` / `MINSG` | 右栏补位项 |

标题下的**风险画像**把三个风控指标翻译成人话（如「中高波动 · 回撤偏大 · 性价比差」）。
指标缺失（第三方接口不可用）时该格不渲染，全缺则显示「暂无健康指标数据」，
不会阻断页面其他部分；养鸡的饱食 / 心情 / 健康 / 亲密改为一行文字，不再占用进度条位置。

## 净值走势图细节

基金详情页的走势图是自绘 SVG（`public/js/chart.js`，无图表库依赖）：

- 平滑曲线（Catmull-Rom 转贝塞尔）+ 渐变面积，**涨红跌绿**按所选区间的整体涨跌取色
- 虚线网格 + 右侧净值刻度 + 首/中/末日期 + 区间最高/最低点标记 + 最新点高亮
- 指针移动（含触摸）显示十字准星与提示气泡：日期、净值、较区间起点涨跌

## 报告模块

报告库不再占主导航位（底部 Tab / 侧栏只有 3 项：鸡舍 / 发现 / 我的），入口是**鸡舍右栏「分析报告 → 查看全部 N 份 ›」**；
「分析报告」卡片本身直接展示最新 3 份报告，点条目进详情（返回按钮回鸡舍），点「查看全部」进独立的报告库页面：

- 报告库页（`#/reports`）顶部有「← 鸡舍」返回按钮，页面内搜索与筛选逻辑不变
- 列出全部已上传报告，支持关键词搜索（标题/基金名/代码）与筛选（全部 / 未关联 / 已关联）
- 列表只显示**人能读懂的纯文本摘要**（HTML 报告先剥掉 `<script>/<style>/<head>` 与标签），解析状态、原文与 HTML 源码都放进「查看」详情里，不在列表堆标签
- **新增**（三种方式）：
  - `上传文件`：PDF / MD / TXT / CSV / **HTML** / 图片，≤20MB
  - `粘贴文本`：直接粘贴 Markdown、纯文本或 HTML 源码（格式可选「自动识别」）
  - `开放接口`：生成给 AI 的调用提示词，复制给任意 AI 助手即可让它生成报告并调用开放接口写入报告库（见下）
- **查看 / 重新解析 / 删除**：
  - **HTML 报告**：点「全屏打开」直接在新标签打开原文 `GET /api/v1/reports/{id}/raw`，**整屏渲染上传的 HTML 本体**（带严格 CSP，脚本不执行、外链不加载；缺 viewport 时后端自动补一个，手机上不会缩成小字）
  - **Markdown / 文本 / 文件**：跳到报告详情页 `#/report/{id}?from=reports|fund/{code}`（带来源返回按钮），展示 AI 摘要/要点/风险与正文
- **关联管理**：未关联的报告可一键「关联基金」，已关联的可「更换关联」；
  每张卡片右下角有一枚胶囊直接显示挂在哪只基金上（`🔗 基金名 代码`，点击跳到基金详情，未领养额外标「未领养」），未关联则显示虚线「未关联基金」

### 开放接口与 AI 提示词

「新增报告 → 开放接口」提供两份可一键复制的提示词（HTML 格式为默认且重点支持）：

- 提示词内含完整接口说明（端点、Header、请求体 JSON 示例、错误码约定）
- HTML 版要求 AI 输出**自包含 HTML**：样式写在 `<style>` 内联标签、不引用外部 CDN / 图片 / 字体、**不含 `<script>`**、移动端友好、结尾附免责声明且不出现投资建议表述
- 前端预览 HTML 报告时使用 `<iframe sandbox>`（不开启 `allow-scripts`）+ 服务端响应头严格 CSP（`default-src 'none'`），双重隔离，报告里的脚本不会执行、外链资源不会加载
- 基金详情页「AI 提示词」按钮复用同一套提示词生成器（`GET /api/v1/ai-prompt?code=005827&format=html|markdown`）

基金详情页「研究报告」区与之联动：

- 「新增报告」默认关联当前基金（复用同一上传弹窗）
- 「关联已有」可从报告库中挑选报告挂到当前基金（`PATCH /api/v1/reports/{id}`）
- 每份报告卡片只显示纯文本摘要，详情（AI 要点、风险、HTML 沙箱预览）统一走「查看」
- AI 解析对 HTML 报告会先剥标签再交给模型，解析结果落库前也统一去标签（`stripTags`），避免存进一堆尖括号

## 入场门槛：设了持仓才进鸡舍

「自选」是观察池，「鸡舍」才是真的养鸡。判定口径统一为 `cost_price > 0 && shares > 0`（成本价与份额都填了才算建仓）：

- 自选页（`#/funds`）也**不在主导航**：入口是鸡舍「我的鸡舍」标题旁的 `📋 自选` 按钮，页顶有「← 鸡舍」返回按钮
- 领养时成本价 / 份额留空 → 只进自选，不进鸡舍
- 未入场的基金：不出现在鸡舍卡片、不计入鸡舍概况（持仓市值 / 累计盈亏 / 今日估算 / 涨跌家数）、不结算每日事件、不衰减、不参与欠照料检查，也不能喂食 / 抚摸（接口返回 `no_position`）
- 自选页卡片标「👀 未入场 / 未设置持仓 · 暂不进鸡舍」，按钮直接变成「设置持仓」；**列表下方的提示条**说明有几只还没入场（不打扰浏览，滚到底才看到）
- 自选页顶部「筛选条件」下拉框：`全部 / 已入场（在鸡舍）/ 未入场（只看）/ 今日上涨 / 今日下跌 / 持仓盈利 / 持仓亏损 / 饿了`（`GET /api/v1/funds?filter=...`）；筛完没有结果时可一键「清除筛选」（同时把分组切回全部）
- 旁边的「基金类型」下拉框按东财 FTYPE 大类过滤：`全部类型 / 股票型 / 指数型 / 混合型 / 债券型 / 货币型 / QDII / FOF / 其他`（`GET /api/v1/funds?type=index` 这类，取 `funds.type`），可与筛选条件、分组、排序自由组合
- 详情页「我的持仓」对未建仓的基金给出提示条，一键「设置持仓」
- 清空成本价或份额 = 退出鸡舍，回到自选观察（`PATCH /api/v1/funds/{code}` 传空字符串即清空）
- `GET /api/v1/funds` 额外返回 `positioned` / `watching` 两个计数；`GET /api/v1/yard` 额外返回 `watching` 与 `watchItems`

**鸡舍排序**：「我的鸡舍」标题右侧的下拉可选 默认 / 仓位 / 收益率 / 今日涨跌 / 名称，
排序**只重排已有 DOM 节点**（`resortCards()` 用 `appendChild` 移动卡片），不重新渲染、不重新请求，卡片上的点击与「调整持仓 / 抚摸」按钮全部保留；
选择记在 `localStorage.ff.yardSort`，下次进页面按上次的排序展示。

**鸡舍类型筛选**：排序左侧的「类型」下拉只列出**鸡舍里真实存在的基金类型**（带只数，如「指数型 3」）+「全部」，
切换只改卡片 `display`（`applyTypeFilter()`），不重渲染、不重新请求，与排序可任意叠加；
只数显示为「共 3 / 4 只」，选择记在 `localStorage.ff.yardType`，退出/放归后该类型不存在时自动回落为「全部」。

< -20%         韭菜         0% ~ 10%       养基新秀
-20% ~ -5%     养基小白     10% ~ 20%      稳健养基人

## 饲料（经验值）规则

**饲料 = 经验值，只增不减，且只由两个真实产出渠道产生**：

| 行为 | 饲料变化 |
| --- | --- |
| 上传报告（文件 / 文本 / HTML / AI 接口都算） | **+20**（`POST /reports*` 返回 `feedGain`） |
| 写一条投资心得（≥10 字） | **+8**，每天最多计 5 条，防复制粘贴刷经验 |
| 签到 | **已下线**（`GET /me/checkin` 返回 410） |
| 领养新鸡 | 不再送饲料（只记录 `last_adopt_at`） |
| 完成每日任务 | 不再发饲料（待办只保留「待完成 / 已完成」） |
| 喂食 / 加餐 | **不再消耗饲料**（只要求附报告或心得），因此 `no_feed` 不会再出现 |

- 「我的」页展示 `饲料（经验）/ 已解锁成就 / 累计互动`，并有一行说明当前两个加饲料的渠道。
- 成就解锁仍然一次性发放饲料（里程碑奖励），任务完成不发放。

## 核心玩法规则

| 当日涨跌幅 | 事件 | 状态变化 |
| --- | --- | --- |
| ≥ +2% | 下金蛋 | 心情 +12，成长 +8 |
| +0.5% ~ +2% | 下蛋 | 心情 +8，成长 +5 |
| -0.1% ~ +0.5% | 散步 | 心情 +2，成长 +3 |
| -1.5% ~ -0.1% | 掉 1 根毛 | 心情 -6，成长 +2 |
| -3% ~ -1.5% | 掉 3 根毛 | 心情 -12，健康 -3 |
| ≤ -3% | 躲雨 | 心情 -20，健康 -8 |

- 连续上涨 ≥3 天：成长值 ×1.5；连续下跌 ≥3 天：进入情绪低谷，抚摸后恢复成长。
- ⚠️ **鸡的「成长等级」（Lv.1 雏鸡 … Lv.5 金鸡）已整体下线**：发现页的等级体系卡片、鸡舍 / 自选卡片的 `Lv` 徽章、动态里的「成长值 +N」、`level_3` / `level_5` 两个成就都已移除（成就列表从 17 项变 15 项）。
  引擎仍会累计 `growth` 字段（历史数据不删），但不再作为任何展示或排序依据；用户侧唯一的等级是「养基等级」（按收益率定级）。
- 每 24 小时未互动：饱食 -10 / 心情 -5 / 健康 -2（有下限，鸡不会「死亡」）。
- 鸡舍天气由上证指数涨跌映射（晴 ≥+0.8% / 多云 / 阴 >-2% / 雨 >-3% / 雷雨 ≤-3%），影响全体心情（+5 / 0 / -3 / -8 / -12）。
- 天气条本身也是「会动的」：两团柔光在背景里缓慢漂浮（`wb-drift` 22s）+ 一道高光周期扫过（`wb-sheen` 9s）+ 入场时轻微上浮（`wb-in`）；
  宽度 ≥700px 时中间补一句天气闲话（`W_TIPS`，如「云层有点厚，正适合躺着看鸡」）占住留白，窄屏自动隐藏，保证「天气 / 今日总盈亏」先读到；
  指数与涨跌家数做成小胶囊，手机上固定换到第二行。系统开启「减弱动效」时全部静止。
  天气图标是纯 CSS 动画（`public/js/weather.js` + `style.css` 的 `.wx-*`）：
  晴为太阳自转光芒 + 呼吸缩放，多云/阴为多朵云不同速度漂移，雨为云下连续落雨，雷雨再加常驻闪电（周期性闪两下）；
  系统开启「减弱动效」时（`prefers-reduced-motion`）自动静止。
- **等级只与陪伴时长和照料投入有关，与收益率无关**（产品价值观，勿改）。

## 照料与投研素材（互动要有实际投入）

互动不是点一下就完事，每次照料都必须留下真实的投研痕迹：

| 动作 | 前置要求 | 效果 |
| --- | --- | --- |
| 喂食 🌾 | 必须附一份**报告**（`report_id`）或一条 **≥20 字投资心得**（`note`） | 饱食 +25 / 亲密 +3 / 成长 2 + 加成（报告 +5，心得 +3） |
| 抚摸 🤲 | 必须写一条 **≥10 字心态笔记** | 心情 +15 / 亲密 +2 / 成长 1 + 加成（心得 +1），并解除情绪低谷 |
| 喂全场 🌾🌾 | 同一份素材（报告或 ≥20 字心得），成长加成递减 | 依次喂饱所有不饿的鸡 |

> 「打扫 / 放音乐」这类**纯点击动作已下线**：它们不产生任何信息，只是刷数字。健康改为靠带素材的喂食维持（每次 +4，高于每日衰减 -2）。

**鸡舍卡片上的两个按钮**：`🌾`（视觉沿用原来的加餐图标，点击 = **调整持仓**：改成本价 / 份额 / 昵称 / 建仓日，保存后盈亏、仓位、体型与各页统计立即重算，清空成本价或份额 = 退出鸡舍）+ `🤲 抚摸`。
喂食 / 加餐移到了基金详情页的「投研心得 → 用报告/心得加餐」与「今日待办」里，避免在列表上误点。

- 素材会写入「投研时间线」：基金详情页的「投研心得」区可查看与删除（`GET/POST /notes`、`DELETE /notes/{id}`）
- 用报告加餐时，若该报告还没关联基金，会自动挂到被投喂的这只鸡上
- 「今日待办」只保留需要真实产出的动作（喂食 / 安抚 / 复检持仓 / 读报告 / 传研报 / 研究新基 / 写心得），每条可**点击直达对应功能**：喂食自动选中最饿的那只、安抚自动选今天跌得最多的那只、复检直接打开鸡详情页

AI 上传报告示例（Markdown / 纯文本）：

```bash
curl -X POST http://127.0.0.1:3290/api/v1/funds/005827/reports \
  -H "Authorization: Bearer fa_xxx" -H "Content-Type: application/json" \
  -d '{"title":"2026Q2季报解读","tags":["AI生成"],"content_type":"markdown","content":"...","parse":true}'
```

AI 上传 **HTML 报告**（重点支持的格式）：

```bash
curl -X POST http://127.0.0.1:3290/api/v1/funds/005827/reports \
  -H "Authorization: Bearer fa_xxx" -H "Content-Type: application/json" \
  -d '{"title":"005827 深度分析","tags":["AI生成","HTML"],"content_type":"html",
       "content":"<!doctype html><html><head><meta charset=\"utf-8\"><style>...</style></head><body>...</body></html>",
       "parse":true}'
```

`content_type` 可选 `html` / `markdown` / `text`；省略时自动识别（`.html` 后缀、或正文以 `<!doctype html>` / `<html` 开头即判定为 `html`）。

## 部署要点

- 单端口服务，PM2：`pm2 start ecosystem.config.cjs && pm2 save`
- 子路径部署：设置 `.env` 的 `BASE_PATH=/fundFarm`，Nginx 用 `proxy_pass http://127.0.0.1:3290;`（**不带尾斜杠**，保留前缀），前端全部走相对路径
- 根路径部署：`BASE_PATH` 留空即可
- 数据安全：`data/`（SQLite 库 + 上传报告）不在版本库中，部署时只覆盖源码，切勿整体覆盖运行目录
